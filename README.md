# Restaurant Business AI

AI Business OS around the Restaurant Digital Ordering System (DOS).

The existing DOS remains the protected product core. This repository contains the business automation layer around it.

## Human-in-the-loop
When a restaurant becomes genuinely interested, the workflow pauses for human sales and relationship handling. The owner closes the deal and confirms commercial terms and requirements.

## DOS integration
Use controlled, explicit DOS interfaces. Agents must not directly edit arbitrary DOS source code, production data, deployment configuration, security controls, or pricing rules.

## Commercial model
- Basic: KES 45,000 setup / KES 4,500 monthly
- Professional: KES 75,000 setup / KES 8,500 monthly
- Enterprise: KES 150,000+ setup / KES 15,000–25,000+ monthly
- First 3 Founders: KES 40,000 setup / KES 4,500 monthly

Agents must not change commercial rules without explicit human approval.
